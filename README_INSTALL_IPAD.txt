DA40 NG OLB — ИНСТРУКЦИЯ ПО УСТАНОВКЕ НА iPAD (БЕЗ КОДА И MAC)
====================================================================

Чтобы программа работала на iPad на весь экран и 100% ОФЛАЙН через
Safari («На экран «Домой»»), её нужно один раз выложить на бесплатный
HTTPS-хостинг (GitHub Pages). После установки на iPad интернет больше
не понадобится — все тексты, eQRH и 12 схем кэшируются в память iPad.

--------------------------------------------------------------------
ШАГ 1. Распакуй архив на ПК
--------------------------------------------------------------------
Распакуй DA40NG-OLB-v1.zip — внутри будет папка DA40NG-OLB с файлами:
  • index.html
  • manifest.json
  • sw.js
  • css/
  • js/
  • data/
  • assets/

--------------------------------------------------------------------
ШАГ 2. Выложи на бесплатный GitHub Pages (5 кликов)
--------------------------------------------------------------------
1. Зайди на https://github.com и войди (или создай бесплатный аккаунт).
2. Нажми зелёную кнопку «New» (создать новый репозиторий):
   • Repository name: da40ng-olb
   • Выбери: Public (обязательно для бесплатного Pages)
   • Нажми «Create repository».
3. На открывшейся странице нажми синюю ссылку «uploading an existing file».
4. Открой на ПК распакованную папку DA40NG-OLB, выдели ВСЁ ВНУТРИ НЕЁ
   (index.html, manifest.json, sw.js, css, js, data, assets) и перетащи
   мышкой прямо в окно браузера.
   ВАЖНО: перетаскивай именно СОДЕРЖИМОЕ папки DA40NG-OLB, чтобы файл
   index.html лежал в корне репозитория!
5. Дождись загрузки файлов и нажми зелёную кнопку «Commit changes».
6. В верхнем меню репозитория перейди: Settings → Pages (слева).
   • В разделе «Branch» выбери: main  и папку  /(root) → нажми Save.
7. Подожди 1–2 минуты и обнови страницу Settings → Pages — сверху
   появится твоя ссылка вида:
   https://<твой-ник>.github.io/da40ng-olb/

--------------------------------------------------------------------
ШАГ 3. Установка на iPad (как нативное приложение)
--------------------------------------------------------------------
1. Открой эту ссылку в браузере Safari на iPad.
2. Подожди 3–5 секунд, пока в верхней панели загорится «OFFLINE READY».
3. Нажми кнопку «Поделиться» (квадрат со стрелкой вверх) →
   «На экран «Домой»» (Add to Home Screen) → «Добавить».
4. Закрой Safari и запусти иконку «DA40 NG OLB» с рабочего стола iPad.
5. Можешь включить Авиарежим и проверить — всё работает без интернета!

--------------------------------------------------------------------
СОВЕТЫ ПО ИСПОЛЬЗОВАНИЮ:
• Кнопка EN / RU в правом верхнем углу мгновенно переключает язык
  документов прямо на открытой странице (интерфейс остаётся на EN).
• Кнопка DAY / NIGHT переключает дневную и ночную тему (схемы тоже
  автоматически инвертируются под ночную кабину).
• Layer 1 / Layer 2 / Layer 3 — три независимые вкладки: можно держать
  открытыми одновременно Limitations, eQRH и Схемы систем.
• Маркер (жёлтый / зелёный / красный / CLR): выбери цвет на панели
  и просто нажимай на нужные абзацы. Всё сохраняется в памяти iPad.
• Вкладка DATA / BACKUP позволяет выгрузить все твои заметки и маркеры
  в резервный файл .json.
